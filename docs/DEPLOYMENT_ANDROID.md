# Déploiement Android

Configuration générée : `compileSdk 36`, `targetSdk 36`, `minSdk 24`, Java/Kotlin 17, AGP 9.0.1 et Gradle 9.1.0. Le SDK d’exécution Gradle est le JDK 21 d’Android Studio.

La signature release doit utiliser un keystore externe au dépôt et `flutter build appbundle`. Les permissions, App Check Play Integrity, Data Safety et la politique de confidentialité devront être validés avant publication.
