# Site de présentation InvoiceAI

Ce dossier contient le site React de présentation et son mini espace de création de documents.

## Lancer le site

```powershell
cd website
pnpm install
pnpm dev
```

Le site vitrine est accessible à la racine. Le bouton principal ouvre l’application sur `#/app/devis`, avec deux menus : création de devis et génération de facture.
